Структура повторяет заготовку: **часть А** — что решение обязано обеспечивать, **часть Б** — что
владелец хочет добавить. Для каждого пункта: что уже есть (с доказательством), чего нет, задача,
приоритет. Статусы проверены по документам проекта и живым замером Jetson 12.10 06:17 UTC

**Как читать.** Приоритет: **P0** — сейчас, **P1** — быстрые победы для семьи, **P2** — надёжность
глубже, **P3** — крупные функции, **P4** — умный дом. Трудозатраты: S (день), M (неделя), L (больше).
Исполнитель по правилу №16: **К** — Claude (ведущий), **С** — субагент Sonnet, **Д** — DeepSeek,
**В** — владелец (sudo, деньги, решения, семья).
