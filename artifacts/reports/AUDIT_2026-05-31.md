## 5. Переменные в `config/.env.example`, не используемые в коде / Variables in `config/.env.example` not used in the code

🇷🇺 Эти переменные оставлены как «зарезервировано на будущее» или для документации,
но прямо в compose/скриптах сейчас не читаются — можно либо реализовать, либо
удалить:

🇬🇧 These variables were left as "reserved for the future" or for documentation
purposes, but are not currently read directly in compose/scripts — they can either
be implemented or removed:

🇷🇺

- `PUID`, `PGID` — типично для Linuxserver-образов; в наших compose не нужны.
- `JETSON_LAN_IP`, `NEXTCLOUD_HOST`, `IMMICH_HOST`, `LLM_GATEWAY_HOST` — только
  для reverse-proxy секции (Caddy/Traefik), которой пока нет.
- `IMMICH_DISABLE_MACHINE_LEARNING=true` — должен быть передан в compose как env
  для `immich-server`/`immich-machine-learning`, сейчас не передаётся.
- `POSTGRES_NEXTCLOUD_PASSWORD` — дубликат `NEXTCLOUD_DB_PASSWORD`, нигде не
  читается. Удалить или переименовать.
- `LLM_DAILY_TOKEN_LIMIT`, `LLM_MONTHLY_COST_LIMIT_USD`,
  `LLM_ALLOW_FILE_CONTENT_UPLOAD`, `LLM_ALLOW_IMAGE_ANALYSIS` — для policy
  enforcement в LLM Gateway; пока не имплементировано в `services/llm-gateway/app/main.py`.
- `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL` — fallback-провайдер, в
  коде сейчас только DeepSeek-ветка.
- `BACKUP_RETENTION_*` — передаются через `restic forget` в скрипте напрямую
  цифрами, не через env.

🇬🇧

- `PUID`, `PGID` — typical for Linuxserver images; not needed in our compose files.
- `JETSON_LAN_IP`, `NEXTCLOUD_HOST`, `IMMICH_HOST`, `LLM_GATEWAY_HOST` — only
  for the reverse-proxy section (Caddy/Traefik), which does not exist yet.
- `IMMICH_DISABLE_MACHINE_LEARNING=true` — should be passed into compose as an env
  var for `immich-server`/`immich-machine-learning`, currently not passed.
- `POSTGRES_NEXTCLOUD_PASSWORD` — duplicate of `NEXTCLOUD_DB_PASSWORD`, not read
  anywhere. Remove or rename.
- `LLM_DAILY_TOKEN_LIMIT`, `LLM_MONTHLY_COST_LIMIT_USD`,
  `LLM_ALLOW_FILE_CONTENT_UPLOAD`, `LLM_ALLOW_IMAGE_ANALYSIS` — for policy
  enforcement in the LLM Gateway; not yet implemented in `services/llm-gateway/app/main.py`.
- `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL` — fallback provider; the
  code currently only has the DeepSeek branch.
- `BACKUP_RETENTION_*` — passed via `restic forget` directly as numbers in the
  script, not through env.

🇷🇺 **Рекомендация:** на Stage 2 либо реализовать чтение этих переменных, либо
вычистить из шаблона.

🇬🇧 **Recommendation:** in Stage 2, either implement reading of these variables or
clean them out of the template.
