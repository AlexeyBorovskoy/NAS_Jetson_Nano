# Точка 2026-11-20: пилот Codex CLI

[English](CHECKPOINT_2026-11-20_CODEX_VPS_PILOT.md), [предыдущая точка](CHECKPOINT_2026-11-16.ru.md)

Ограниченный пилот Codex CLI на шведском VPN-хосте: закреплённая версия 0.171.0, одна непривилегированная учётка, отдельная политика, сессия с лимитами ресурсов.

- G0-A ранее: синтетические S01–S10 прошли, но инструмент прочитал фиктивный файл того же UID; пробел в покрытии ресурсов задокументирован, вход не запускался.
- G0-S2 (одобрено владельцем): пять выбранных файлов конфигурации/запуска и жёсткие агрегированные лимиты ресурсов на срез пользователя; очередь SOFT, не жёсткий допуск одного агента.
- Первый R1-01 упал до команды инструмента: управляемый запрет чтения конфликтовал с загрузчиком CLI.
- После одобренного исправления единой политики R1-01 снова упал до выполнения инструмента: bwrap пытался создать каталог на ФС только для чтения.

Сбой запуска не доказывает защиту чтения. Остановлена только пилотная сессия, политику далее не ослабляли. Остальные проверки R1/R2 не выполнялись. Серверные проверки «до/после» и сверка слушателей прошли; свежих тестов Android E2E/полосы нет.

Юнит пилота и срез пользователя неактивны: сокета и cgroup нет; постоянная агрегированная конфигурация ресурсов сохранена. Свежая проверка предела ядра прошла при активном срезе; не действующая cgroup и не полный тест нагрузки.

Вердикт: NO-GO для G1. Реальные входы ChatGPT/Google, ключи/биллинг, второй контур, IDE-сервер и миграция проекта не выполнялись. Частные доказательства/конфигурации остаются локально, намеренно вне Git.

Следующий шаг: только отдельно одобренная диагностика или изменение; автоматического третьего ослабления нет; OAuth только после приёмки критических тестов и отдельного одобрения G1.
