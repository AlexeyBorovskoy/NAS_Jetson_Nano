# 03_CHANGE_PLAN — План изменений и пакет согласования G1

## Пакет G1 — Пилот Sweden VPN v2 на Windows и Android (ЗАПРОС НА СОГЛАСОВАНИЕ)

### 1. Цель
Подтвердить в реальной домашней/мобильной сети (без второго VPN `AmneziaVPN`) устранение задержки первого подключения и работоспособность обоих транспортов (`SE-PRIMARY` REALITY TCP/443 + `SE-HY2` UDP/443) с профилем v2.

### 2. Что изменяется / что НЕ изменяется
- **VPS Sweden (`45.140.13.178`):** **БЕЗ ИЗМЕНЕНИЙ** (`sing-box` не перезапускается, `config.json` не меняется, firewall/DNS/SSH не трогаются).
- **Старые YAML v1 (`C:\Users\Alexey\.ssh\new-vps-se\`):** **НЕ ИЗМЕНЯЮТСЯ И НЕ ОТЗЫВАЮТСЯ** (остаются рабочим откатом).
- **Пилотные устройства (2 шт.):**
  1. `alexey-windows` — импорт `.agent-work/private-releases/sweden-v2/alexey-windows/alexey-windows-v2.yaml` в `FlClash` (как отдельный новый профиль, рядом со старым v1).
  2. Один Android (например, `hagircbmsszlx4in` при подключении по USB или `olga-android`/`ivan-android` на этапе пилота) — импорт соответствующего `*-v2.yaml` в `FlClash` без удаления старого профиля.

### 3. Ожидаемое прерывание и независимый канал управления
- На время живого пилота на `alexey-windows` потребуется временно отключить `AmneziaVPN` (`tun2`), чтобы трафик шёл напрямую через домашнюю сеть и не срабатывал SNI-перехват `www.googletagmanager.com`.
- Перед началом пилота сохраняется возможность мгновенно вернуть `AmneziaVPN` или переключиться на старый профиль v1 в `FlClash`.

### 4. Preflight / Postflight
- **Preflight:** проверка SHA-256 v2-профиля, нативная валидация `mihomo.exe -t`, фиксация маршрутов до включения.
- **Postflight:** 30 запусков или серия замеров `T_ready` в домашнем Wi-Fi (цель `p95 ≤ 8 с`), проверка `SE-PRIMARY` и `SE-HY2` по отдельности, проверка egress `45.140.13.178`, проверка `no DIRECT leak`.

### 5. Rollback
1. В `FlClash` переключить активный профиль обратно на v1 (`380671665593389056` / `FAMILY-SE-Alexey-Windows.yaml`).
2. При необходимости включить `AmneziaVPN`.
3. Серверная часть не менялась, серверный откат не требуется.
