# 07_CLIENT_PILOT_SPEC — Спецификация пилота v3 (S4)

1. **Пилотные устройства:** `olga-android` / `hagircbmsszlx4in` (Android `com.follow.clash`) и `alexey-windows` (Windows `FlClash`).
2. **Обязательные измерения:**
   - **Холодный старт (`t0 -> t_success`):** 30 запусков в домашнем Wi-Fi (`p95 ≤ 8 с`) и LTE (`p95 ≤ 12 с`), включая все неуспехи/тайм-ауты.
   - **Раздельная проверка транспортов:** `SE-PRIMARY` (REALITY) и `SE-HY2` (Hysteria 2) по отдельности.
   - **Failover (`AUTO`):** при клиентской недоступности одного транспорта новый запрос должен уйти через резервный `≤ 10 с`.
   - **Fail-closed:** при отказе обоих транспортов `0` утечек в `DIRECT` для защищаемого трафика.
   - **Системные приложения и IPv6:** проверка браузера/приложений через `VpnService` (не только `adb forward`) и проверка отсутствия IPv6/DNS утечек.
   - **Windows (`alexey-windows`):** временно остановить `AmneziaVPN` (`tun2`), включить TUN в `FlClash` и замерить `30` холодных стартов + `REALITY` без SNI-перехвата.
