## 3. Изменения на VPS 08.10 (с разрешения владельца)

- **Подкачка.** `/swapfile` 512 МБ (создан 02.11.2024) выпал из `/etc/fstab` при его перезаписи
  18.06.2026 — почти четыре месяца VPS жил без подкачки. Возвращён: строка в `fstab` (проверено
  `swapoff` + `swapon -a`), `vm.swappiness=10` в `/etc/sysctl.d/60-nas-swap.conf`, бэкап
  `/etc/fstab.bak.1791437180`. Правило №13 до/после без изменений, пиров 23 = 23.
  Откат: `swapoff /swapfile`, вернуть `fstab` из бэкапа, удалить conf, `sysctl vm.swappiness=60`.
- **Правило:** `ssh … 'systemd-run --quiet --scope -p MemoryMax=256M -p MemorySwapMax=0 bash -s' < script.sh`;
  журнал — только потоком и с `--since`. `MemorySwapMax=0` обязателен: с подкачкой неудачная команда без
  него не умрёт, а дольше будет тянуть VPN вниз.
