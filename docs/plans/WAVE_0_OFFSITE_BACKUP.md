## Архитектура: Vostro забирает сам

Ключевое ограничение — **оба узла за NAT и ни один не принимает входящие**.
Jetson за CGNAT, Vostro в корпоративной сети с исходящим доступом. Значит:

```
Vostro ──исходящий SSH──> VPS 95.163.176.103:22
                            │
                            └─ ProxyJump ─> 127.0.0.1:10022 ─> Jetson
```

`10022` на VPS — уже существующий обратный туннель Jetson, слушает **только
loopback**. Новых портов не требуется.

**Направление выбрано не случайно:** инициирует Vostro, потому что только он
может. Побочная выгода — Jetson не хранит учётных данных для записи на Vostro;
компрометация Jetson не даёт доступа к off-site копии.

Схема работы: Vostro забирает дампы к себе, затем кладёт их в **локальный
restic-репозиторий** `/srv/nas-offsite`. Restic шифрует — посторонний на чужой
машине увидит непрозрачные блобы.

их в этот момент. Владелец это принял (машина в корпоративной сети организации), но это
свойство, а не недосмотр, и оно должно быть известно.

## Что делать при возобновлении

1. ~~Авторизовать ключ на VPS~~ — **сделано 22.08, подтверждено 24.08** (см. выше).

2. ~~Авторизовать тот же ключ на Jetson~~ — **сделано 22.08, подтверждено 24.08** (см. выше).

3. **Проверить сквозной путь** до установки чего-либо:

   ```bash
   ssh -o ProxyCommand="ssh -i ~/.ssh/id_nas_offsite -W %h:%p root@95.163.176.103" \
       -p 10022 -i ~/.ssh/id_nas_offsite admin@127.0.0.1 "hostname"
   ```

4. **Установить restic** на Vostro (`apt-get install -y restic`).

5. **Создать репозиторий** `/srv/nas-offsite`. Пароль репозитория — root-only
   файл на Vostro, **и обязательно копия вне обеих машин**: без пароля
   репозиторий не открыть, и тогда бэкап бесполезен ровно тогда, когда нужен.

6. **Начать с малого:** сперва дампы БД (150 МБ) — они проверяют всю цепочку
   целиком. Фотографии Immich (5.8 ГБ) добавлять вторым заходом, когда цепочка
   доказана.

7. **Таймер на Vostro**, ночью, с ограничением ввода-вывода — рядом живёт
   боевой сервис, который должен отвечать людям.

8. **Проверить восстановление.** Бэкап, из которого ни разу не восстанавливали,
   бэкапом не является. В этом проекте это уже проверялось на практике.

9. Вписать занятое в `HOST_CONTRACT.md` на Vostro и сообщить на доску —
   добавляется systemd-таймер на чужую боевую машину.
