# Исходные данные для планирования развития / Roadmap input

**Дата / Date:** 2026-08-30.

# Current State

Домашнее облако на Jetson Nano 4 ГБ: Immich (7098 ассетов), Nextcloud (162 таблицы, 5 пользователей), Samba (2 шары), LLM Gateway (3 провайдера), Talk-бот `@бобик`. 13 контейнеров, все стабильны (0 рестартов). Живое устройство работает на до-переименовочном деплое, git — на переименованном; расхождение частично устранено сегодня (Часть A плана `tranquil-wandering-truffle.md`), физический переезд ожидает.

# What Works Well

- Все 13 контейнеров healthy, `restart: always`, ноль OOM/рестартов на момент замера.
- Бэкапы БД работают и дважды проверены реальным восстановлением (2026-08-09, 2026-08-24).
- Reverse-туннель к VPS + VPN — стабильны, температуры/throttling в норме, GPU/CPU с запасом.
- Секреты организационно закрыты (права 600/640), `check_no_secrets.sh` теперь работает без ложных срабатываний.
- Инженерная культура проекта: документированные «грабли» с датами и обоснованием, отозванные ошибочные диагнозы, комментарии в коде объясняют «почему», не «что».

# What Is Fragile

- Единственная копия семейных фото (Immich, ~6-9 ГБ) — только на локальном SSD.
- API `nasa-api` — единственный сервис без пиннинга зависимостей, несёт auth-логику.
- `storage_preflight.sh` не проверяет явно свободное место.
- Reproducibility = C: реальные значения `.env` существуют только на устройстве.
- SD-карта (корень ФС) без активного мониторинга износа — юнит готов, не развёрнут.

# What Is Obsolete

- Ubuntu 18.04.6 LTS (EOL 04/2023), Python 3.6.9 (EOL 12/2021) — платформенный потолок Jetson Nano/JetPack 4.6.1.
- `docker-compose.stage1.yml` — легаси-слепок, использование не подтверждено.
- Переменные DuckDNS в `.env.example` — актуальный DNS давно на dynv6.
- ~13 dangling Docker-образов (2.5-3 ГБ).

# What Must Be Preserved

- Правило №2/13: работоспособность VPN на VPS для ~19 клиентов — не трогать `amnezia-*` контейнеры без проверки до/после.
- Правило №3: LAN-профиль `nasa-lan`/сеть `192.168.0.0/24`, адрес `.50`.
- SSD/HDD USB-quirks (`usb-storage.quirks=...`) — устранённая когда-то нестабильность, легко регрессирует.
- Существующая схема секретов (права 600, .env вне git).
- Restic offsite-репозиторий на Vostro (Фаза 1) — не заменять, расширять (Фаза 2 — фото).

# Hardware Limitations

Jetson Nano 4 ГБ — потолок для одновременного Immich+Nextcloud+Postgres×2+Redis×2+LLM Gateway+Talk-API+мониторинг. RAM уже используется на 51-54% в простое. GPU/CUDA/TensorRT технически доступны (JetPack 4.6.1), но без запаса RAM для ML-инференса рядом с текущей нагрузкой. USB 3.0 SuperSpeed для SSD/HDD уже используется на практическом максимуме (250/172 МБ/с SSD).

# Software Limitations

Python 3.6.9 системный — сервисы обязаны жить в Docker со своим современным Python (уже так и есть, но это привязка к контейнеризации без права на «просто systemd-сервис» для нового Python-кода). Docker 20.10.7 — не последняя ветка, но достаточна.

# Security Limitations

CORS `*` на API, непроверенный SSH `PasswordAuthentication`/`PermitRootLogin`, EOL база ОС без подтверждённого ESM, 10 незаротированных `.env.bak.*`. Ничего CRITICAL — периметр (наружу с VPS только 22/443/40568, с Jetson — ничего напрямую) соблюдён.

# Performance Limitations

Throttling не обнаружен, температуры с запасом (44-50°C против порога ~90-97°C). `load average` 2.52 при 4 ядрах — умеренная нагрузка с запасом. Узкое место — RAM, не CPU/температура.

# Maintainability Limitations

Два источника состояния проекта (README и CLAUDE.md) синхронизируются вручную — README отстаёт. Смешанная политика пиннинга зависимостей. Test coverage maturity = 1 (единичные тесты) — регрессии в auth/PII-редактировании/OCS-парсинге уже случались и не покрыты тестами.

# Opportunities

- Фаза 2 offsite-бэкапа фото (уже в «Ближайших задачах»).
- Развернуть `coturn` на VPS для рабочих видеозвонков Talk вне LAN.
- Развернуть уже готовый в git мониторинг износа SD-карты.
- Закрепить версии зависимостей и Docker-тегов — низкая сложность, устраняет реальный риск дрейфа.

# Candidate Modernization Areas

Часть B миграции устройства (каталог/systemd/логи) — уже спланирована (`docs/plans/tranquil-wandering-truffle.md`). Централизованный сбор логов контейнеров (сейчас `json-file` без проверенных лимитов). Явная политика ротации `.env.bak.*`.

# Candidate New Features

Фаза 2 offsite-бэкапа фото Immich. TURN-релей для звонков Talk. Возможный локальный CV/AI на Jetson — технически возможен (JetPack 4.6.1 готов), но конкурирует за RAM с текущими сервисами — реалистично только при переносе части нагрузки на другой узел (Vostro/VPS) или при добавлении RAM/замене платы.

# Migration Constraints

Jetson Nano — тупиковая ветка JetPack (4.6.1, не обновляется дальше). Любое существенное развитие AI/ML-направления упрётся в необходимость нового Jetson (Orin Nano/NX) или переноса инференса на другой узел. Физический переезд текущего деплоя (Часть B) требует окна обслуживания — трогает внешний туннель и USB-watchdog.
